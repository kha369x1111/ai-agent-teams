# KALTRON | مفتاح الأسرار السبعة — الألف (ا)

**الألف… سر الحرف الذي لا ينحني**
من الألف تبدأ الحروف… وفي الاستقامة يبدأ الوجود.

فيلم قصير عمودي (9:16 · 1080×1920 · 30 FPS) في سبعة مقاطع + خاتمة سيادية،
بصوت رجولي جهوري، وترجمة عربية متزامنة تُبنى من التوقيت الفعلي للإلقاء.

| الملف | الوصف |
|---|---|
| `deliver/alif_1080x1920.mp4` | الفيلم النهائي: 1080×1920 · 30 FPS · H.264 · AAC 192k · −15 LUFS · 46 MB |
| `deliver/alif_subtitles.srt` | الترجمة العربية المتزامنة (63 سطرًا، من توقيت الإلقاء الفعلي) |
| `index.html` | صفحة عرض محلية: مشغّل + المقاطع + منشور النشر |
| `deliver/cover.jpg` | الغلاف المصغر للريلز (1080×1920) |
| `deliver/cover_preview.jpg` | نسخة مصغّرة للمعاينة |
| `deliver/post.md` | منشور النشر + بيانات الغلاف + نص الإفصاح الإلزامي |
| `docs/production.md` | الموجز الإنتاجي الكامل، النصوص، الترجمة، والأمانة المعرفية |
| `docs/timeline.md` | جدول المقاطع واللقطات بالتوقيت |
| `audio/vo/s1…s7.mp3` | التعليق الصوتي الأصلي (قبل المعالجة) |
| `storyboard/raw/*.png` | اللوحات السبع + الغلاف — **بلا أي حروف** |

## التشغيل

```bash
cd alif-film
python3 -m pip install --break-system-packages pillow numpy uharfbuzz imageio-ffmpeg python-bidi
python3 tools/build.py plan                    # التوقيتات
python3 tools/build.py audio                   # معالجة الصوت + الموسيقى + المزج
python3 tools/build.py render                  # تركيب الإطارات والترميز
python3 tools/build.py cover                   # الغلاف
# ملاحظة: render يُنتج ماسترًا ثقيلًا (~260MB). للنسخة المنشورة:
#   ffmpeg -i deliver/alif_1080x1920.mp4 -vf hqdn3d=1.2:1.2:2.5:2.5 \
#          -c:v libx264 -crf 23 -preset slow -c:a copy deliver/alif_small.mp4
python3 tools/build.py docs                    # الوثائق ومنشور النشر
python3 tools/build.py all                     # كل ما سبق بأمر واحد
python3 tools/build.py stills --times 12,45,100 --sheet   # إطارات معاينة
```

## خط الإنتاج

```
audio/vo/*.mp3 ─► audio.prepare  (تقطيع الصمت، EQ، ضغط، طبقة أوكتاف، تحليل الكلام)
                        │
tools/spec.py ──────────┼─► plan.build ─► _work/plan.json (مقاطع/لقطات/نصوص/ترجمة)
                        │
              audio.score (درون + أوتار + إمباكتات + رنين معدني) ─┐
                        └─► audio.mix (ducking + reverb + loudnorm) ─┤
storyboard/raw/*.png ─────────────────────────────────────────────┤
                        └─► frames.Compositor ─► frames.encode ─► deliver/*.mp4
```

## قرارات هندسية

- **النص العربي بلا libraqm:** Pillow هنا مبني بدون محرّك تشكيل عربي، لذلك
  `tools/artext.py` ينفّذ خوارزمية Bidi (python-bidi) → مقاطع اتجاهية → HarfBuzz
  (mirroring للأقواس في RTL) → تحويل محيط كل محرف إلى مضلّعات → تعبئة الحبر
  وإفراغ الثقوب بعمق التعشيش. النتيجة: نصوص عربية متصلة وصحيحة، وأرقام لاتينية
  لا تنقلب (`28` لا تصبح `82`).
- **شكل الألف:** يُرسم من محرف Amiri الأصلي (قاعدة ١) ثم يُعطى جسمًا معدنيًا
  بتدرّج أفقي، قلبًا من نور، وهالة داكنة تفصله عن الإضاءة الخلفية.
- **الصوت المهيب:** سلسلة EQ (تعزيز 105Hz، خفض 320Hz، حضور 2.9kHz) + ضاغط
  + طبقة أوكتاف منخفضة (0.84×) لمضاعفة الجسامة، ثم خفض الموسيقى −8 dB تحت الكلام.
- **الترجمة المتزامنة:** تُشتق من مقاطع الكلام المكتشفة داخل الصوت نفسه، لا من تقدير
  عدد الحروف، لذلك لا تنزلق ولا تتراكم.

## الالتزام بقواعد الإنتاج الثماني

1. شكل الألف صحيح — محرف Amiri حقيقي، لا تشويه ولا توليد.
2. لا وجوه مشوّهة — الشخص الوحيد في الفيلم من الخلف، بلا وجه.
3. لا نصوص داخل الصور — كل اللوحات المولّدة خالية من الحروف (فُحصت بصريًا وأُعيد توليد لوحتين).
4. النصوص العربية كلها مركّبة في المونتاج بالكود.
5. لا ادّعاء علمي — تنبيهات صريحة داخل المقاطع ٢ و٤ و٥، وبطاقة إفصاح في الخاتمة.
6. لا مؤثرات كرتونية — درون كوني، إمباكتات، رنين معدني، أوتار داكنة.
7. هوية الأكاديمية — شعار هندسي (نجمة ثمانية + سبع نقاط) والاسم في الخاتمة والغلاف.
8. تصاعد درامي — من الصمت والخط الواحد إلى الذروة في المقطع ٦ ثم الاستقرار.
