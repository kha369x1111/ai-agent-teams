# 🖥️ دليل التشغيل بدون CMD - Windows GUI

## تشغيل البوت بطريقة سهلة مثل أي برنامج عادي

---

## 🎯 عندك 4 طرق للتشغيل

### من الأسهل للأصعب:

```
1️⃣ بنقرة واحدة (.bat)           ← الأسهل ⭐
2️⃣ تطبيق سطح المكتب (GUI)       ← جميل ومريح
3️⃣ CMD يدوي                     ← للمطورين
4️⃣ PowerShell                   ← متقدم
```

---

## 🚀 الطريقة 1: بنقرة واحدة (الأسهل) ⭐

### فقط اضغط مرتين!

```
📁 في مجلد smc-ict-bot ستجد:

📄 MENU.bat          ← القائمة الرئيسية
📄 START.bat         ← تشغيل البوت مباشرة
📄 DASHBOARD.bat     ← فتح Dashboard
📄 NOTEBOOKS.bat     ← فتح Jupyter
📄 APP.bat           ← تطبيق سطح المكتب
📄 desktop_shortcut.bat ← إنشاء اختصارات سطح المكتب
```

### الاستخدام:

```
1️⃣ أول مرة فقط:
   • اضغط مرتين على desktop_shortcut.bat
   • سيتم إنشاء اختصارات على سطح المكتب

2️⃣ كل مرة بعدها:
   • اضغط على "Trading Bot" في سطح المكتب
   • اختر ما تريد من القائمة
```

## 🎨 الطريقة 3: اختصارات سطح المكتب

### أول مرة - التشغيل:

```
1. اذهب لمجلد المشروع
2. اضغط مرتين على: desktop_shortcut.bat
3. سيتم إنشاء 3 اختصارات على سطح المكتب:

   🖥️ Trading Bot      → يفتح تطبيق سطح المكتب
   📊 Dashboard        → يفتح Dashboard مباشرة
   📓 Trading Notes    → يفتح Jupyter
```

### بعد ذلك:

```
• اضغط على أي اختصار في سطح المكتب
• يعمل مثل أي برنامج Windows عادي!
```
