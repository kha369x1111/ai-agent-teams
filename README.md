# ai-agent-teams

مستودع أنظمة **فرق الوكلاء** (Multi-Agent Teams) — كل نظام محرك تنسيق + بطاقات وكلاء + بوابات جودة إلزامية.

## الأنظمة

### 1) طاولة التداول المؤسسية — `trading-desk/` 🆕
12 وكيلًا بهيكل مؤسسي حقيقي (Front / Middle / Back Office):
- **4 محللين بالتوازي** (ماكرو · فني · تدفقات · كمي/VaR) — مستقلون لا يرى أحدهم عمل الآخر
- **بوابتان إلزاميتان:** مدير المخاطر (سيناريوهات باحتمالات + وقف + ميزانية مخاطرة) ثم الالتزام (تدقيق نهائي)
- **أحجام صفقات بمعادلات ظاهرة** (مخاطرة 1%، سقف ¼ كيلي، heat ≤ 5%، رافعة ≤ 2×)
- **تنفيذ ورقي وسجل صفقات** + **لجنة مراجعة أسبوعية** تغلق حلقة التحسن

```bash
cd trading-desk
python3 trading_orchestrator.py jobs/desk_2026-09-12      # جلسة مرجعية كاملة (طيار مساعد)
python3 daily_desk.py                                     # جلسة يومية جديدة
python3 daily_desk.py --mode review                       # لجنة المراجعة الأسبوعية
```

التوثيق الكامل: [`trading-desk/README.md`](trading-desk/README.md)

> ⚠️ إخلاء مسؤولية: النظام تعليمي — تحليل وتخطيط لمحفظة ورقية فقط، ليس نصيحة استثمارية
> ولا ينفذ أوامر حقيقية.

### 2) فريقا الوكلاء الأصليان — `agent-team-bundle.zip`
حزمة تحتوي نظامين مستقلين:
- **فريق إنتاج المحتوى** (8 وكلاء): استراتيجية → بحث → كتابة → مراجعة → توزيع → تصميم → إعلانات
- **فريق تحليل العملات الرقمية** (7 وكلاء): بيانات → 3 محللين بالتوازي → بوابة مخاطر → تقرير يومي

فك الضغط ثم راجع `agent-team-clean/README.md`.

## الفلسفة المشتركة
فصل الصلاحيات + بوابات آلية (عناصر إلزامية يتحقق منها المحرك) + أثر تدقيق كامل في
`status.json` — لا مخرج يمر بلا بوابة، ولا قرار بلا توثيق.
