# فرق الوكلاء — ai-agent-teams

مستودع يضم ثلاثة مشاريع مستقلة للتجربة والتطوير. اختر المجلد المناسب واقرأ تعليماته قبل التشغيل.

| المشروع | الغرض | نقطة البداية |
|---|---|---|
| [طاولة التداول الورقية](trading-desk/README.md) | إعداد موجز وتحليل مخاطر وسجل لصفقات افتراضية عبر أدوار متعددة | `trading-desk/daily_desk.py` |
| [بوت SMC/ICT](smc-ict-bot/README.md) | تجارب تحليل وتنفيذ باستراتيجية السيولة؛ يتطلب مراجعة الإعدادات والمفاتيح قبل التشغيل | `smc-ict-bot/main.py` |
| `agent-team-bundle.zip` | حزمة مضغوطة لنظامي إنتاج المحتوى وتحليل العملات | فك الحزمة واقرأ README داخلها |

## بدء سريع لطاولة التداول

```bash
cd trading-desk
python3 trading_orchestrator.py jobs/desk_2026-09-12
python3 daily_desk.py --manual
```

المثال الموجود في `jobs/desk_2026-09-12/` مادة مرجعية مؤرخة، وليس بيانات سوق حية. يصف [دليل الطاولة](trading-desk/README.md) مراحل الوكلاء وبوابات المخاطر والالتزام وكيفية تشغيل وضع المراجعة.

## الإعداد والأسرار

لكل مشروع تعليمات ومتطلبات منفصلة. استخدم ملفات `.env.example` أمثلةً لأسماء المتغيرات فقط، وضع القيم الحقيقية في `.env` المحلي. لا ترفع مفاتيح المنصات أو رموز Telegram إلى Git. ابدأ بالمحاكاة أو الشبكة التجريبية، وافحص مسار التنفيذ قبل تفعيل أي تداول حقيقي.

## حدود الاستخدام

الطاولة تنتج خططًا وسجلات ورقية ولا تنفذ أوامر سوق حقيقية. البوت مشروع منفصل يحتوي مسارات اتصال وتنفيذ؛ لا تفترض أن ضمانات الطاولة تنطبق عليه. المخرجات تعليمية وليست توصية استثمارية، ويجب اختبار كل مكون مستقلًا قبل الاعتماد عليه.
