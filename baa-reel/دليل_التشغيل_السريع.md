## أولاً: روابط التحميل المباشرة (تعمل فوراً بضغطة واحدة)

1. **تحميل المشروع الكامل مع الفيديو النهائي بصيغة ZIP (موصى به للتشغيل الفوري):**
   - `https://codeload.github.com/kha369x1111/ai-agent-teams/zip/refs/heads/arena/0b6566ab-ai-agent-teams`
2. **تحميل حزمة مشروع حرف الباء الخفيفة وحدها بدون الفيديو (`~4.2 MB` فقط):**
   - `https://github.com/kha369x1111/ai-agent-teams/raw/arena/0b6566ab-ai-agent-teams/baa-reel/downloads/baa-reel-light-runnable.zip`
3. **تحميل ملف الفيديو النهائي `MP4` وحده (`1080×1920` · `54.6 MB`):**
   - `https://github.com/kha369x1111/ai-agent-teams/raw/arena/0b6566ab-ai-agent-teams/baa-reel/deliver/baa_secret_reel_1080x1920.mp4`

## ثانياً: طريقة التشغيل على جهازك بعد فك الضغط

### 1. على نظام Windows 10 / Windows 11 (فوري — بضغطة مزدوجة)
1. فك ضغط ملف الـ `ZIP` وافتح مجلد `baa-reel`.
2. لمشاهدة الفيديو مباشرة بدون أي خادم: افتح `deliver\baa_secret_reel_1080x1920.mp4`.
3. لتشغيل **استوديو العرض السينمائي التفاعلي الكامل**: اضغط مرتين على:
   ```text
   START_WINDOWS.bat
   ```
   *(يعتمد على مكتبة Python القياسية فقط — لا يحتاج `pip install`، ويفتح الاستوديو فوراً على `http://127.0.0.1:8088`).*
4. إذا أردت تعديل النصوص أو المشاهد في `project\reel_spec.py` وإعادة رندر الفيديو بالكامل من الصفر على ويندوز، اضغط مرتين على:
   ```text
   REBUILD_REEL_WINDOWS.bat
   ```

### 2. على نظام macOS أو Linux
افتح الطرفية (`Terminal`) داخل مجلد `baa-reel` ونفّذ:
```bash
chmod +x START_MAC_LINUX.sh
./START_MAC_LINUX.sh
```
ولإعادة بناء الفيديو من الصفر على macOS / Linux:
```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
bash make_reel.sh
```
