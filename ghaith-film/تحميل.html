git clone https://github.com/kha369x1111/ai-agent-teams.git
cd ai-agent-teams/ghaith-film

كيف تحرّك الصور؟ (ثلاث طرق)

  1. حركة كاميرا جاهزة: غيّر move أو focus للقطة في project/shots_data.py ثم أعد الرندر.
  2. تحريك بعمق 2.5D (مُنفَّذ): 
    python3 tools/parallax.py --all --strength 1.2
    ينتج مقاطع في storyboard/clips/ يلتقطها محرك الرندر تلقائيًا.
  3. تحريك الشخصيات فعليًا: استخدم أداة Image-to-Video (Runway / Luma / Kling) بالبرومبت الجاهز في docs/animation-guide.md، وضع الناتج في storyboard/clips/<اسم_الصورة>.mp4.
