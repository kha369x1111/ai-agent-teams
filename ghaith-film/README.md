# فريق الحراسة السرّي: مرحباً بك يا غيث

فيلم قصير ثلاثي الأبعاد للأطفال والعائلة (٣–١٠ سنوات) — فصحى مبسطة، أسلوب Pixar/Disney،
ألوان دافئة، إضاءة سينمائية ناعمة. **المدة النهائية: ٤ دقائق و٤٩ ثانية** (٢٨٩ ثانية، ٣٨ لقطة).

هذا المجلد مشروع إنتاج كامل: السيناريو، دفتر الشخصيات، دفتر اللقطات، حزمة برومبتات الصور،
التعليق الصوتي العربي، الموسيقى والأنشودة، الترجمات العربية، وكل أدوات التركيب التي تُنتج
ملف `out/ghaith_alhurras_1080p.mp4` بأمر واحد.

---

## ١. المخرجات

| الملف | الوصف |
|---|---|
| `out/ghaith_alhurras_1080p.mp4` | الفيلم الكامل 1080p/24 · H.264 · AAC مع الترجمات والصوت |
| `out/poster.jpg` | صورة الغلاف |
| `index.html` | صفحة عرض تفاعلية: مشغّل + فصول + حوار قابل للنقر + كلمات الأنشودة |
| `docs/shotlist.md` | دفتر اللقطات + الحوار الكامل بالتوقيت |
| `docs/character-bible.md` | دستور الشخصيات (المظهر، الصوت، الدافع الدرامي) |
| `docs/prompts.md` | حزمة البرومبتات الجاهزة لكل لقطة (نسخة إنجليزية للتوليد) |
| `storyboard/raw/*.png` | صور اللقطات المولّدة |
| `audio/lines/*.mp3` | مقاطع التعليق الصوتي (يُقسَّم المقطع الجماعي آليًا) |

## ٢. التشغيل

```bash
cd ghaith-film
python3 -m pip install --break-system-packages pillow numpy uharfbuzz imageio-ffmpeg
python3 tools/build.py plan     # جدول اللقطات والتوقيتات
python3 tools/build.py cards    # بطاقتا البداية والنهاية
python3 tools/build.py all      # الحزمة القديمة (ffmpeg filters)
# أو المسار الموصى به (ذاكرة ثابتة، دقة إطارية):
python3 tools/render.py --timeline build/timeline.json --audio build/mix.wav \
                        --out out/ghaith_alhurras_1080p.mp4
```

خط الأنابيب:

```
script/lines.json ─┐
project/shots.json ─┼─► tools/build.py (timeline) ─► tools/score.py (موسيقى)
audio/lines/*.mp3 ─┘        │                        │
                            ▼                        ▼
                  tools/artext.py (نص عربي)     build/mix.wav (ducking + loudnorm)
                            │                        │
                            └────► tools/render.py ──┘─► out/*.mp4
                                        │
                                 tools/report.py ─► docs/* + صفحة العرض
```

## ٣. حلول هندسية داخلية

- **النص العربي:** Pillow هنا مبني بدون `libraqm`، فالحروف تظهر مفكّكة. الحل في
  `tools/artext.py`: تشكيل بـHarfBuzz (`uharfbuzz`)، تحويل كل محيط الحرف إلى مضلّع،
  حساب **عمق التعشيش** لكل محيط لتعبئة الحبر وإفراغ الثقوب (ط/ظ/ك/ل/ع…)، ثم تنعيم بـPillow.
- **الكاميرا:** لقطات ثابتة تُحرَّك رقميًا بمسار كاميرا (زوم/بان/تلت) + تلاشٍ ناعم بين اللقطات،
  مع إعادة تحجيم بمضاعف 2× لتقليل الاهتزاز.
- **الصوت:** موسيقى مولّدة إجرائيًا (`tools/score.py`)، تعليق صوتي يوضع زمنيًا، وducking
  بـ`sidechaincompress` ثم `loudnorm` إلى −16 LUFS.
- **الأنشودة:** تُبطَّأ بمعامل `atempo=0.85` لتصبح إيقاعية، وتُعرض كلماتها كاريوكي.

## ٤. حدود الإنتاج الحالية (شفافية)

- الصور **مولّدة بالذكاء الاصطناعي كصور ثابتة** ثم تُحرَّك ككاميرا (animatic سينمائي).
  ليست رسومًا متحركة بإطارات مُحرَّكة يدويًا؛ إنتاج حركة كاملة يحتاج مسار 3D (Blender/Unreal)
  أو نموذج فيديو، ويمكن استبدال `storyboard/raw/*.png` بمقاطع فيديو بنفس الأسماء الموسّعة.
- التعليق الصوتي بصوت واحد (راوية) لكل الشخصيات، بلا تمايز أصوات. لتعدد الأصوات:
  ولّد مقاطع إضافية وضعها في `audio/lines/<id>.mp3` بنفس المعرّفات.

## ٥. الترخيص والحقوق

- الخطوط: **Tajawal** و**Amiri** من Google Fonts — رخصة OFL، نسخها في `assets/fonts/`.
- الصور: مولّدة خصيصًا لهذا المشروع.
- الموسيقى: مولّدة إجرائيًا داخل المستودع (`tools/score.py`).

## ٦. التحميل والتحريك

| ما تريده | الأمر / الملف |
|---|---|
| تحميل المشروع (٢٥ م.ب) | `packages/ghaith-film-light.zip` أو صفحة `تحميل.html` |
| تحميل الكود فقط (٦٩٦ ك.ب) | `packages/ghaith-film-code.zip` |
| تحميل الفيلم | `deliver/ghaith_alhurras_1080p.mp4` |
| إعادة بناء الفيلم بأمر واحد | `bash make_film.sh` (أو `--animate` مع التحريك) |
| تحريك الصور | `python3 tools/parallax.py --all` ثم أعد الرندر |
| دليل التحريك الكامل | `docs/animation-guide.md` |

> الصور محفوظة بصيغة JPEG (‏٩.٩ م.ب بدل ٨٦ م.ب) ويقبلها المحرك تلقائيًا
> بجانب PNG. المقاطع المتحركة تُوضع في `storyboard/clips/<اسم_الصورة>.mp4`
> ويلتقطها `tools/render.py` تلقائيًا (الأولوية: مقطع جاهز ← صورتك ← حركة كاميرا).
