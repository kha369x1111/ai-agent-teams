# خطوات إنتاج الفيلم — مشروحة ببساطة

> تخيّل أن الفيلم **كيكة**. أنت الآن تملك كل المكوّنات: الدقيق (الصور)، السكر (الأصوات)،
> والفرن (الكود). المطلوب منك فقط أن **تضعها في الفرن وتضغط الزر**. وبعد أن تخرج الكيكة،
> يمكنك تزيينها كما تحب — أو تركها كما هي، فهي لذيذة أصلًا. 🎂

**أهم شيء تعرفه:** الفيلم **جاهز ومكتمل** (٤ دقائق و٢٢ ثانية). الخطوات القادمة ليست
«إصلاح» بل **تجميل واختيار**: تغيّر صوتًا، تحرّك صورة، تعدّل كلمة. كلها اختيارية.

---

## الخطوة ٠ — افتح الصندوق 📦

1. اضغط على ملف `ghaith-film-light.zip` بالزر الأيمن ← **استخراج الكل / Extract All**.
2. ستحصل على مجلد اسمه `ghaith-film`.
3. افتحه. ستجد داخله: `index.html` (صفحة المشاهدة) و`tools` (الأدوات) و`storyboard`
   (الصور) و`audio` (الأصوات) و`docs` (الأوراق).

> ⚠️ لا تفك الضغط داخل مجلد التحميلات مباشرة إن كان فيه ملفات كثيرة. اعمل مجلدًا جديدًا
> اسمه «فيلم غيث» وضع الملفات فيه.

---

## الخطوة ١ — اطمئن أن كل شيء سليم ✅

افتح الطرفية (Terminal على ماك/لينكس، أو **PowerShell** على ويندوز) داخل مجلد المشروع،
واكتب:

```bash
python3 tools/doctor.py
```

سترى قائمة مثل:

```
✅ بايثون 3.11 موجود
✅ مكتبة numpy
✅ برنامج ffmpeg (محرّك الفيديو) جاهز
✅ الصور موجودة (23 صورة)
🎉 كل شيء جاهز!
```

- كل العلامات ✅ ← انتقل للخطوة ٢.
- ظهرت ❌ ← أمامها **جملة الحل** مباشرة. أشهر حالة: مكتبة ناقصة، والحل:
  ```bash
  pip install --break-system-packages pillow numpy uharfbuzz imageio-ffmpeg
  ```
  (على ويندوز تكون `python -m pip install ...` بدون `--break-system-packages`.)

## الخطوة ٢ — شغّل الفرن 🔥

```bash
bash make_film.sh --animate
```

ماذا يحدث؟ (البرنامج نفسه يخبرك بكل خطوة)

| المرحلة | ما يفعله | الوقت |
|---|---|---|
| ① التبعيات | يتأكد أن الأدوات موجودة | ثوانٍ |
| ② البطاقات | يرسم بطاقة العنوان وبطاقة «النهاية» | ثوانٍ |
| ③ الجدول الزمني | يحسب متى يظهر كل سطر وكل لقطة | ثوانٍ |
| ④ التحريك | يعطي كل صورة إحساس عمق (طبقتان تتحركان) | — |
| ⑤ الترجمات والصوت | يكتب ٤٢ ترجمة، يخلط ٤ أصوات + الموسيقى | دقيقة |
| ⑥ الرندر | ينتج الفيلم النهائي إطارًا بإطار | **١٠–٢٠ دقيقة** |

> ⏳ الرندر بطيء لأنه يرسم ٦٢٨٥ صورة ويضغطها. اتركه يعمل، واذهب اشرب شايًا. 🍵
> على جهاز أضعف قد يأخذ ٢٥ دقيقة. هذا طبيعي وليس خطأ.

**تريد فيلمًا أسرع للتجربة؟** جرّب جزءًا منه فقط:

```bash
python3 tools/render.py --timeline _work/timeline_full.json --audio _work/mix.wav \
        --out deliver/تجربة.mp4 --from 0 --to 30
```

هذا ينتج أول ٣٠ ثانية فقط.

## الخطوة ٣ — شاهد النتيجة 🍿

افتح الملف:

```
deliver/ghaith_alhurras_1080p.mp4
```

أو شاهده في الصفحة الحلوة: افتح `index.html` بنقرة مزدوجة (يعمل في المتصفح بلا إنترنت)،
وستجد الفيلم + الفصول + الحوار + كلمات الأنشودة.

**تريد صفحة تعمل على هاتفك أو تشاركها؟** شغّل خادمًا صغيرًا:

```bash
python3 tools/serve.py --port 8080
```
ثم افتح `http://localhost:8080` في المتصفح — وبنفس الشبكة يمكن لأهلك فتحه من الهاتف
عبر عنوان جهازك (مثل `http://192.168.1.5:8080`).

## الخطوة ٤ — كيف أغيّر شيئًا؟ (القاعدة الذهبية) 🔑

**القاعدة الذهبية: استبدل الملف بنفس الاسم.**

الفيلم مبني من ثلاث «علب»:

| العلبة | المكان | ماذا تضع فيها |
|---|---|---|
| 🖼️ الصور | `storyboard/raw/` | `s01_livingroom.jpg` … إلخ |
| 🎙️ الأصوات | `audio/lines/` و`audio/lines_wav/` | `02_khaled.wav` … إلخ |
| 📝 النصوص | `script/lines_data.py` | كلمات الحوار والأنشودة |

مثال بسيط: تريد أن يكون **صوت نانا مختلفًا** عن سوسو؟

1. سجّل صوتًا (أو استخدم أداة تحويل نص إلى كلام، انظر الخطوة ٦).
2. احفظه باسم `04_nana.wav` **بنفس الاسم بالضبط**.
3. ضعه في `audio/lines_wav/` (واحذف القديم أو انقله لمجلد احتياطي).
4. أعد تشغيل `bash make_film.sh --animate`.
5. سيظهر صوتك في الفيلم. ✨

**تعديل كلمة في السيناريو؟** افتح `script/lines_data.py` بالمفكرة (Notepad)، غيّر النص
بين علامتي التنصيص `"..."`، احفظ، وأعد التشغيل. **لا تلمس** `{"id": ...}` — هي اسم الملف
الصوتي المقابل فقط.

## الخطوة ٥ — تحريك الشخصيات (الجزء الممتع!) 🎭

الآن الصور تتحرك بعمق (parallax)، لكن **الوجوه نفسها ثابتة**. لجعل الطفل يرمش، والأب
يبتسم، واليد تمسك بالإصبع — تحتاج أداة «صورة ← فيديو».

### الأدوات (اختر واحدة، كلها تعمل بالمتصفح)

| الأداة | سهولتها | ملاحظة |
|---|---|---|
| **Luma Dream Machine** | ⭐⭐⭐ سهلة جدًا | تعطيها صورة + جملة، تعطيك ٥ ثوانٍ متحركة |
| **Kling AI** | ⭐⭐ متوسطة | أفضل في حركة الوجوه والتعبيرات |
| **Runway Gen-4** | ⭐⭐ متوسطة | خيارات كاميرا دقيقة |
| **Pika** | ⭐⭐⭐ سهلة | حركات صغيرة ولطيفة |
| **Higgsfield / Vidu** | ⭐⭐ | بدائل جيدة |

### الطريقة (٤ خطوات فقط)

1. **ارفع الصورة**: من `storyboard/raw/` (مثلًا `s17_baby_closeup.jpg`).
2. **اكتب جملة الحركة**. انسخ هذا القالب وبدّل الجزء الأخير:
   ```
   Animate this Pixar-style 3D still with subtle, warm family-film motion.
   Camera: slow gentle push-in. Keep faces, clothes and lighting identical.
   {هنا الحركة}
   No morphing, no new characters, no text. 4 seconds, cinematic.
   ```
   أمثلة جاهزة تضعها مكان `{هنا الحركة}`:
   - للطفل: `The newborn's eyes open slowly and his tiny fingers curl around the sister's finger.`
   - لنانا: `Nana blinks twice, her eyes glisten, and her smile grows slowly.`
   - للبيت: `Curtains breathe in the breeze, the girl's measuring tape sways, dust motes drift.`
3. **نزّل الفيديو** (MP4).
4. **أعد تسميته بنفس اسم الصورة** وضعه في مجلد جديد اسمه `storyboard/clips/`:
   ```
   storyboard/clips/s17_baby_closeup.mp4
   ```
5. أعد التشغيل: `bash make_film.sh --animate`

> المحرك ذكي: إن وجد مقطعًا في `storyboard/clips` **استخدمه هو** بدل الصورة الثابتة،
> وقصّه أو مدّه ليطابق مدة اللقطة، وأضاف الترجمة والصوت فوقه.
> ستؤكد لك الطرفية: `animated shots: 5/38`.

**نصيحة**: ابدأ بـ ٣ لقطات فقط — وجه غيث، إصبع نانا، وبطاقة العنوان. الفرق سيكون مذهلًا.

## الخطوة ٦ — الأصوات 🎙️

ثلاث طرق، اختر ما يناسبك:

| الطريقة | كيف | التكلفة |
|---|---|---|
| **الجاهزة (موجودة)** | لا تفعل شيئًا — أربعة أصوات جاهزة | مجانًا |
| **صوتك أنت** | سجّل بـ **Audacity** (مجاني) أو تطبيق الهاتف، صدّر WAV، ضعه في `audio/lines_wav/` بنفس الاسم | مجانًا |
| **تحويل نص إلى كلام** | **ElevenLabs** (واقعي جدًا، عربي جيد) أو **Azure TTS** أو **Google Cloud TTS** — الصق النص من `script/lines_data.py` | مجاني محدود / مدفوع |

**لكل شخصية ملف خاص بها** — هذا ما يجعل الفيلم يبدو حقيقيًا:

| الشخصية | الملف |
|---|---|
| الراوية | `00_intro.mp3`, `03_narrator.mp3`, ... |
| خالد | `02_khaled.wav`, `05_khaled.wav`, `07_khaled.wav`, `18_khaled.wav`, `23_khaled.wav` |
| سارة | `22_sara.wav`, `29_sara.wav` |
| نانا | `04_nana.wav`, `06_nana.wav`, `10_nana.wav`, `15_nana.wav`, `28_nana.wav` |
| سوسو | `08_susu.wav`, `14_susu.wav`, `25_susu.wav` |
| جيجي | `01_gigi.wav`, `11_gigi.wav`, `16_gigi.wav`, `27_gigi.wav` |
| الأنشودة | `09_song.mp3` |

> 💡 إذا أردت **إضافة صوت جديد** لشخصية: احفظ الملف بنفس اسم الملف القديم — لا حاجة
> لتعديل أي كود.

## الخطوة ٧ — الموسيقى والأنشودة 🎵

- **الموسيقى الهادئة**: مولّدة تلقائيًا داخل المشروع (`tools/score.py`) — لا تحتاج شيئًا.
- **الأنشودة**: حاليًا **كلام مُلقًى** (ليس غناءً حقيقيًا) بصوت البنات.
  لتحويلها إلى أغنية فعلية:
  1. اذهب إلى **Suno** أو **Udio** (أدوات أغاني بالذكاء الاصطناعي).
  2. الصق كلمات الأنشودة من `script/lines_data.py` (قسم `SONG_LYRICS`).
  3. اختر نمطًا: «أغنية أطفال، لحن مرح، إيقاع بسيط، أصوات أطفال».
  4. نزّل MP3، وأعد تسميته `09_song.mp3`، وضعه في `audio/lines/`.
  5. أعد التشغيل — سيُستخدم في مكانه تلقائيًا.

## الخطوة ٨ — الترجمة والكلمات ✍️

- نص الترجمة يأتي من `script/lines_data.py` (نفس النص الذي يُقرأ).
- لتغيير جملة: عدّل النص هناك ← أعد التشغيل.
- لتغيير **شكل** اللوحة (اللون، الحجم، الموضع): في `tools/build.py`، دالة
  `make_caption` — عدّل `size` و`color` و`y = H - 300 - plate.height`.

## الخطوة ٩ — تصدير نسخ للمشاركة 📤

| المنصة | الأمر |
|---|---|
| يوتيوب (أفضل جودة) | الملف الحالي جاهز كما هو |
| واتساب (حجم صغير) | أضف `--crf 26` في سطر الرندر |
| نسخة 720p أسرع | أضف `--crf 24` ثم صغّر بـ ffmpeg |
| نسخة عمودية (ريلز/تيك توك) | يحتاج إعادة تأطير — راسلني وأبنيه لك |

مثال نسخة خفيفة:
```bash
python3 tools/render.py --timeline _work/timeline_full.json --audio _work/mix.wav \
        --out deliver/نسخة-واتساب.mp4 --crf 27 --parallax 0.9
```

## مشاكل شائعة وحلولها 🔧

| ما تراه | السبب | الحل |
|---|---|---|
| `command not found: python3` | بايثون غير مثبت | نزّل من python.org وأعد فتح الطرفية |
| `No module named numpy` | مكتبة ناقصة | `pip install --break-system-packages numpy pillow uharfbuzz imageio-ffmpeg` |
| `ffmpeg not found` | محرّك الفيديو ناقص | `pip install --break-system-packages imageio-ffmpeg` |
| الفيلم يخرج أسود أو بلا صوت | ملف صوتي تالف | احذفه مؤقتًا وأعد التشغيل، سيستخدم مدة تقديرية |
| `MISSING AUDIO LINES` في الطرفية | سطر بلا ملف صوت | أضف الملف في `audio/lines_wav/` بنفس اسم السطر |
| الرندر يتوقف فجأة | الجهاز قليل الذاكرة | أغلق البرامج الأخرى، وجرّب أجزاء: `--from 0 --to 120` ثم `--from 120 --to 262` |
| الصور تظهر ممدودة | تغيّر مقاس الصورة | استخدم 1920×1080 أو 1672×941 (نسبة 16:9) |

## خلاصة في ثلاث جمل 🌟

1. **الفيلم جاهز** — شغّل `bash make_film.sh --animate` وشاهده.
2. **لتغيير أي شيء**: استبدل الملف بنفس الاسم (صورة، صوت، أو نص) وأعد التشغيل.
3. **لتحريك الوجوه**: أداة «صورة ← فيديو»، ضع الناتج في `storyboard/clips/` بنفس اسم الصورة، وأعد التشغيل.

بالتوفيق يا بطل — وصوّر لنا أول عرض عائلي 🎬
