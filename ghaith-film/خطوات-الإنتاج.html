كيف تكمل الفيلم؟ 🎬

خريطة طريق بسيطة — خطوة خطوة. تذكّر: الفيلم جاهز أصلًا، وما بعده تجميل واختيار.

☝️ ابدأ من هنا (٣ أوامر فقط)

افتح الطرفية داخل مجلد المشروع، ثم:

python3 tools/doctor.py          # ١) هل كل شيء سليم؟
bash make_film.sh --animate     # ٢) اصنع الفيلم (١٠–٢٠ دقيقة)
python3 tools/serve.py --port 8080   # ٣) شاهده في المتصفح

✅ موجود عندك الآن الفيلم النهائي: deliver/ghaith_alhurras_1080p.mp4 — المدة ٤:٢٢ · ١٠٨٠p · أربعة أصوات.

🔑 القاعدة الذهبية

تريد أن تغيّر شيئًا؟ استبدل الملف بملف جديد يحمل نفس الاسم.
صورة مكان صورة، صوت مكان صوت. ثم أعد التشغيل. لا تحتاج لمس أي كود.

الخطوات بالتفصيل

١

افتح الصندوق 📦

اضغط على الحزمة بالزر الأيمن ← Extract All، وضع الملفات في مجلد اسمه «فيلم غيث».

  • storyboard/raw = الصور
  • audio = الأصوات
  • script = النصوص
  • tools = الأدوات (الفرن)
٢

اطمئن أن كل شيء سليم ✅

شغّل python3 tools/doctor.py. ستظهر علامات ✅ خضراء أو ❌ أمامها الحل.

أشهر مشكلة: مكتبة ناقصة. الحل بسطر واحد:
pip install --break-system-packages pillow numpy uharfbuzz imageio-ffmpeg
٣

شغّل الفرن 🔥

bash make_film.sh --animate

سيصنع: البطاقات ← الترجمات ← خلط الأصوات ← الفيلم. الرندر وحده يأخذ ١٠–٢٠ دقيقة لأنه يرسم ٦٢٨٥ صورة. اتركه واشرب شايًا 🍵

تريد تجربة سريعة؟ اعمل ٣٠ ثانية فقط:
python3 tools/render.py --timeline _work/timeline_full.json --audio _work/mix.wav --out deliver/تجربة.mp4 --from 0 --to 30
٤

شاهد النتيجة 🍿

افتح deliver/ghaith_alhurras_1080p.mp4، أو افتح index.html بنقرة مزدوجة لتشاهد الفيلم مع الفصول وكلمات الأنشودة.

٥

حرّك الشخصيات 🎭

الآن الصور تتحرك بعمق، لكن الوجوه ثابتة. لجعل الطفل يرمش والأب يبتسم:

  • افتح Luma Dream Machine أو Kling AI أو Runway (بالمتصفح).
  • ارفع الصورة من storyboard/raw.
  • اكتب جملة الحركة (القوالب جاهزة في docs/animation-guide.md).
  • نزّل الفيديو، وأعد تسميته بنفس اسم الصورة، وضعه في storyboard/clips/.
  • أعد التشغيل — وسترى animated shots: 5/38 في الطرفية.
ابدأ بثلاث لقطات: وجه غيث، إصبع نانا، وبطاقة العنوان. الفرق مذهل.
٦

غيّر الأصوات 🎙️

ثلاثة خيارات: تترك الأصوات الجاهزة، أو تسجّل صوتك بـAudacity، أو تستخدم ElevenLabs لتحويل النص إلى كلام.

خالد = 02_khaled.wav و05_khaled.wav … وسارة = 22_sara.wav … ونانا = 04_nana.wav … ضع الجديد بنفس الاسم في audio/lines_wav/.
٧

اجعل الأنشودة أغنية 🎵

الكلمات جاهزة في script/lines_data.py (قسم SONG_LYRICS). الصقها في Suno أو Udio، اختر «أغنية أطفال»، نزّل الناتج وسمّه 09_song.mp3 في audio/lines/.

٨

عدّل الكلام ✍️

افتح script/lines_data.py بأي مفكرة، غيّر النص بين علامتي التنصيص ""، واحفظ. لا تلمس {"id": ...} فهي اسم الملف الصوتي.

٩

شارك الفيلم 📤

الملف الحالي جاهز ليوتيوب. لواتساب استخدم نسخة أخف:

python3 tools/render.py --out deliver/واتساب.mp4 --crf 27 --parallax 0.9
